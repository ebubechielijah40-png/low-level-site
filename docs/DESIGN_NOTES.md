# Interface and flow

The visual name is Bare Metal. Black-green surfaces, warm pale-green text, restrained borders, local monospace fonts, a pixel signal motif, and explicit terminal labels connect authentication, navigation, code, and component inspection. The user's exact pixelation reference was not provided, so the current motif is an original interpretation rather than a claimed match to that reference.

## Dashboard arrangement

A persistent left rail provides Dashboard, Learning path, Hardware configuration, Build an OS, and Free terminal. Account identity and POST sign-out sit at the foot. The top strip shows the current workspace location. The content starts with the first unmarked lesson and real completion counts, followed by six numbered language/OS cards in progression order and an open system list. There are no invented streaks or progress points.

## Lesson arrangement

The lesson selector and previous/next links preserve sequence. The left pane holds explanation and practice tabs, including the worked reasoning and controlled failure experiment. The right pane holds editable source, Run, reset, autosave state, and Console/State/Trace/Encoding tabs. There is no new-tab try-it page. The legacy route redirects to the integrated workspace.

A learner may mark a lesson reviewed; that record is not a mastery claim. Reference checks compare the worked example's declared result. Additional experiments can intentionally produce a different result without implying the run engine failed.

## Component arrangement

A system overview has an orbit/zoom model and configuration list. Selecting an available component opens its configuration workspace. There the model and explanation stay left, code/results stay right, and selecting another configured component opens that lab. Mouse/touch dragging rotates; scroll or buttons zoom; component buttons and keyboard arrows provide alternate controls.

The canvas draws boxes and rings with orthographic 3D projection, sorted faces, structural details, labels, and a selection highlight. It is conceptual geometry, not a measured CAD model. Last-run register values and derived telemetry connect visible state to executed code. Quantum probabilities come from an ideal mathematical state, while cryostat geometry remains illustrative.

## OS arrangement

A live emulated text screen, project name, save/import/download controls, ownership-scoped project list, and scope note sit beside the source editor. Imported images have no reconstructed source. Save from that editor creates a separate authored project, preserving the imported bytes. Full ELF execution is explicitly outside the hosted first-stage format.

## Mobile and verification

CSS stacks the panes and hides the navigation rail behind a labelled toggle on small widths. Large tables and source scroll inside their own areas. Reduced-motion preferences suppress the pixel animation. The pixel animation also stops after its brief introductory period.

These responsive behaviours are implemented but their final visual quality still needs the supplied real-browser test on the user's machine. Backend rendering and JavaScript parsing do not replace viewport screenshots or interaction checks.
