What to inspect

Console shows output and errors. State shows variables, registers, virtual memory, or truth tables. Trace records bounded execution steps. Encoding shows instruction words and boot bytes when available.

What the limits mean

Execution has a step and time budget. Output and source are bounded. The run metric measures interpreter work, not processor cycles. Unsupported programs return a clear error.
