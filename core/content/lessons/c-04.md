## One name describes several objects
An array has a fixed number of contiguous elements of one type. `int values[4]` creates four int elements. Valid indices are 0, 1, 2, and 3. The length is four, but index four refers to a position immediately after the final element. Indexing begins at zero because the address calculation is base + index × element size; element zero has zero offset from the base.

In this model each int occupies four bytes, so four elements occupy sixteen bytes. `sizeof(values)` reports the array's total size, while `sizeof(int)` reports one element's size. Their ratio gives the element count when values is still an array object in that scope. When an array is passed to an ordinary C function, it generally decays to a pointer; sizeof that pointer does not recover the original array length. Pass a length explicitly.

## Separate physical and logical bounds
Real C does not generally check array indices at runtime. Reading outside an array's bounds is undefined behaviour, even if the numeric address is inside mapped memory. Our educational interpreter reports an out-of-bounds access to make the mistake visible. That helpful diagnostic is a feature of the runner, not a guarantee that a native C binary will stop safely.

The example has values 4, 8, 12, and 16. It walks indices smaller than the length and computes 40. The independent expected sum is simply 4 + 8 + 12 + 16. Inspect the Variables tab to see the unchanged array and the resulting scalar sum. Array inspection is a structured view of the model, not a raw dump of host memory.

Change the array's element count while leaving the loop's literal bound at four and consider whether the loop still describes the intended object. The relationship between a buffer and its length must remain explicit.

Arrays connect low-level layout to practical software: packet fields, device samples, file blocks, and screen buffers all require accurate lengths. A program that handles a typical input but fails at its boundary is not a correct implementation of the complete requirement.
