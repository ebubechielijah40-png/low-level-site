# Working on Bare Metal

Continue this repository; preserve its Django app and migrations. Do not push, deploy, or publish without the project owner's instruction.

Read README.md, docs/RUNNER_REFERENCE.md, docs/PROJECT_REPORT.md, and docs/TEST_REPORT.md before changing execution or educational scope. The site is a focused low-level learning environment, not a broad machines-mastery repository.

Keep every exercise in the site's workspace. Do not add public external execution services, CDN-only editor dependencies, or arbitrary native execution to the Django request handler. Preserve per-user draft/image ownership, CSRF, individual lesson completion, open configurations, and honest simulation labels.

Teaching must contain actual explanations and worked reasoning. A heading or an instruction to a future author is not a finished lesson. Every added runnable example needs a stated output or state target; tests must compare behaviour, not source-text pattern matches.

Run manage.py check, makemigrations --check --dry-run, manage.py test, tools/verify_examples.py, and tools/http_smoke.py for relevant changes. Run the browser script when changing UI interactions/layout in an environment with a browser. Do not claim its unexecuted results as passed. A native kernel build is not proof of a boot.

Record new limitations and verification evidence. Preserve the user's original files and private data when creating a delivery archive; exclude virtual environments, databases/accounts, credentials, caches, and dependencies.
